# Изображения и шрифты

Изображения созданы для вымышленной коллекции «Форма» встроенным инструментом `image_gen`. Это иллюстрации учебного каталога, а не фотографии реально продаваемых товаров. Финальные файлы находятся в `images/`; исходные PNG преобразованы в WebP без изменения композиции.

## Шрифт

Manrope: локальные кириллический и латинский variable WOFF2, полученные через Fontsource/jsDelivr. Лицензия SIL Open Font License 1.1 находится в `fonts/OFL.txt`.

- Проект шрифта: https://github.com/sharanda/manrope
- Лицензия: https://github.com/google/fonts/blob/main/ofl/manrope/OFL.txt

Favicon представляет собой букву «ф» на зелёном фоне. Логотип магазина набран текстом. Скриншоты `preview-*.png` получены в Chromium из готовой вёрстки.
